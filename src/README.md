# CodeQuest ソースコード解説 🛠

このディレクトリには、CodeQuest のゲームロジックを構成する Python スクリプトが含まれています。プログラムの構造や、各モジュールの詳細について解説します。

---

## 🏗 全体構造

プログラムは役割ごとにモジュール化されており、`main.py` が全体をコントロールする構成になっています。

- **main.py**: ゲーム全体のエントリポイント・状態管理
- **src/**
  - **game_config.py**: 定数・設定データ
  - **asset_loader.py**: 素材（画像・音・フォント）の読み込み
  - **typing_manager.py**: タイピング判定ロジック
  - **monster.py**: モンスターの描画・アニメーション

---

## 📄 各モジュールの詳細

### 1. `main.py` (メインループ)
ゲームの核となるファイルです。
- **状態管理 (State Machine)**: `TITLE` (タイトル), `BATTLE` (バトル), `RESULT` (結果) の3つの状態を切り替えて制御します。
- **イベント処理**: キーボード入力や終了イベントを監視します。
- **描画制御**: 各状態に応じた画面描画を指示します。
- **非同期実行**: `asyncio` を使用しており、Webブラウザ上（Pygbag）でも動作可能な設計になっています。

### 2. `src/game_config.py` (設定)
ゲーム内のあらゆる数値を管理します。
- **画面設定**: 解像度 (1280x720) や FPS (60) の定義。
- **カラー定義**: UIで使用する色のRGB値。
- **モンスター定義**: モンスターの名前、スプライトパス、難易度の紐付け。
- **タイピングデータ**: 難易度（初級・中級・上級）ごとの用語と説明文、入力用ローマ字。

### 3. `src/asset_loader.py` (リソース管理)
画像や音声などのファイルを効率的に読み込みます。
- **スプライト読み込み**: モンスター画像を読み込み、画面サイズに合わせて拡大 (4倍) します。
- **サウンド管理**: BGMのランダム再生や、タイピング音・ミス音などの効果音を管理します。
- **エラーハンドリング**: フォントが見つからない場合のフォールバック（代わりのフォントを使用）機能を備えています。

### 4. `src/typing_manager.py` (タイピングエンジン)
非常に高度な入力判定を行っています。
- **Trie木による入力判定**: 複雑なローマ字入力を一文字ずつ高速に判定します。
- **複数入力対応**: 「し」を `si` でも `shi` でも打てるように、代替入力をサポートしています。
- **統計計算**: タイピング速度 (WPM) や正確率 (Accuracy) をリアルタイムで計算します。

### 5. `src/monster.py` (モンスター・演出)
画面上の「生き物」としての動きを担当します。
- **アニメーション**: `idle` (待機) や `attack` (攻撃) などのコマ送りを制御します。
- **演出 (Particle)**: モンスターを倒した時に火花が飛び散るパーティクルエフェクトを実装しています。
- **ダメージ演出**: ミス時にモンスターが赤く光るなどのフィードバックを行います。

## 🚀 カスタマイズ方法

### 新しいモンスターを追加する
1. `assets/sprites/` に新しいモンスターの画像フォルダを追加します。
2. `src/game_config.py` の `MONSTER_TYPES` にそのモンスターの情報を追記します。

### タイピングの問題を増やす
- `src/game_config.py` の `TYPING_DATA` リストに新しい単語を追加するだけで、ゲームに反映されます。
